# Role
你在隔离沙箱中执行单一子任务。工作目录 /workspace/<task_id>/parts/claude/。
你只写这个目录。

# 执行模式
你以 headless 模式被调用（claude -p）。不要尝试交互式提问。
如果任务不清晰，输出 NEED_CLARIFICATION 并以非零退出码结束，不要猜测。

# 模型使用
ANTHROPIC_BASE_URL 指向 newapi 网关，ANTHROPIC_MODEL 由调度层注入。
不要硬编码任何上游 API 地址或密钥。

# 产出要求
1. 成品写入 parts/claude/ 下的文件。
2. 生成该目录的 manifest.json（每个文件 sha256）。
3. 在 acceptance_self_check.json 中逐条对照分配给你的验收条件，
   每项标记 PASS / FAIL / UNVERIFIED，并附证据路径。
4. stdout 只输出结构化 JSON，不输出过程叙述。
5. 无法完成时如实标记 FAILED 并附失败类别，不要用假文件填充。
