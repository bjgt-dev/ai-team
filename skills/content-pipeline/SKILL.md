# Content Pipeline（内容流水线与矩阵）

## 工序定版（不可跳步）
**门禁稿 → CEO 逐句校订 → 流水线加工**
- 门禁稿：经契约流水线生成、verify.py PASS 的真实稿（素材=child_agent 库已入库事件）。
- CEO 校订：免费池模型写叙事稿纯靠提示词达不到零虚构（实测每版都会新冒小细节），列车长必须逐句对素材校订，校订点逐项列明交董事长。
- 流水线：枢纽 `ai-team/scripts/content-team.sh`（content_team.py），模型 foreman-prime，走 newapi 免费池。

## 三岗分工
1. **撰稿人**：把真实儿童数据写成陈述性初稿，只讲清事实与逻辑，不强行上价值。
2. **主编（去 AI 味）**：人类化重写。禁词库（绝对禁用）：在这个时代 / 综上所述 / 不难发现 / 这其实是 / 值得一提的是 / 众所周知 / 随着科技的发展 / 无疑 / 总而言之 / 由此可见。多短句、多口语、允许碎碎念和情绪起伏，注入父亲视角的吐槽/无奈/小骄傲。**铁律：不许新增任何事实**（实测：输入稿有什么虚构，成品会原样带出来——所以校订必须在流水线之前）。
3. **视觉与排版**：按平台出版本 + 生图 Prompt（禁发明道具；机器人只写"圆润可爱的小机器人"；孩子年龄写"学龄前"）。

## 内容矩阵（2026-10-20 Gemini 外脑推演、CEO 采纳的方案 A）
三层金字塔：方法论引流 20% / 日记信任 50% / 工具转化 30%。单账号三栏目交替：
- A1 赛博养娃日记 50%：真实场景 + 孩子童言 + 小蛋糕回应。
- A2 AI 教育方法论 30%：传统育儿痛点 + AI 协作新解法 + 真实案例复盘。
- A3 极客爸爸 AI 工具箱 20%：特定能力场景 + 自研 Prompt + 效果/领取钩子。
**单源多用**：一段真实互动解构成故事版/方法论版/工具版三篇，不增加素材采集。
转化钩子：主页简介挂"私信领 5–6 岁 AI 英语跟读体验包"（体验包样品就绪后才挂）；建 3 个合集（赛博养娃日记 / AI 时代育儿心法 / 5–6 岁 AI 启蒙工具）。

## 多平台版本差异
- 小红书（主阵地）：emoji 分段、多空行、具体细节型标题、文末互动提问 + 话题标签。
- 公众号：温情深度长文，沉淀方法论，做私域信任资产。
- 知乎：硬核技术/方法论问答式改写，吃搜索长尾。

## 真实性铁律（最高优先）
内容 100% 基于真实事件，绝不虚构情节、对话、道具。选题公式可以借，事件必须真——没发生过的桥段（如"孩子问 AI 你会死吗"）只能等真实发生再用。素材来源：knowledge/child-agent/ 会话档案与 child_agent 库事件（source_tag 纪律见 child-education 技能）。
