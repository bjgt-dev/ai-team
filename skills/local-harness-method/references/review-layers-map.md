# 我们现有审核层 vs garden-skills（对照表，2026-11-06）

## 我们现在有几层

| 我们有的 | 对应五层 | 审什么 | 什么时候开 | 备注 |
|---|---|---|---|---|
| **双顾问**（ChatGPT 发散 + Claude 批判，DeepSeek 为 L1 默认顾问） | L3 内容层（两个角度） | 新方向/大决策/花钱/事故复盘：还有什么可能、哪里会翻车 | 触发门才开；日常执行不开 | 流程：发散 → 收敛 → 批判 → 修订 → 双确认；同意 = 无否决性意见；修订最多两轮；僵局交董事长拍板 |
| **verifier 五条封堵** | L1 结构层 + L5 可执行层 | 代码交付：源文件在合同路径、AST 含非空函数/类、新目录重跑合同测试、红绿检查、只有测试输出驳回 | 每次代码交付 | 现状：第 1、5 条已接，第 2、3、4 条未接——等于结构层只通了一半 |
| **M4 golden-set-100** | L3 内容层（能力抽查） | 模型能力：total ≥85，分层 LIGHT ≥27、MEDIUM ≥22、COMPLEX ≥21、REASONING ≥18；现 80/100 差 5 分，禁改题凑分 | 定期跑 | 是抽查，不是每轮验收 |
| **独立复核**（复核席） | L3 内容层 + 终审（单视角） | 交付物终审：G2 三件、流水线验收、M3/M4/M5 派工都经独立复核通过 | 交付节点 | 只有一个复核者、一个视角，不是三视角 |
| **金丝雀 / 合同测试 / 健康三问** | L5 可执行层（持续） | 网关可用池、管线契约、三问体检；变色才报 | 持续 | 机器层，成本低，开得全 |
| **stall-scan / 每周 5% 复核** | 抽查机制 | 队列积压、已完成交付抽查 | 每周 | 有抽查意识，但只覆盖 DONE 抽查，不覆盖审核层本身 |

## 和 garden-skills 比，缺哪几层

| 缺的层 | 表现 | 后果实例 |
|---|---|---|
| **L2 事实层（系统化）** | 没有“每个数字追到源”的固定动作；verifier 只查结构不查内容真假 | 曾把“已完成”等同于 HTTP 200、把单次快照当现行事实、把用户侧未验证当已验证；董事长多次纠正“无证据不发言” |
| **L4 风格层（清单化）** | 脱名、结论先行、≤300 字都只在记忆里，没有打勾清单 | 汇报反复变长、贴过程、写真实姓名；同一错误多次出现，靠董事长骂才改 |
| **终审三视角** | 独立复核只有一个视角；没有编辑/视觉/技术三分工 | 交付物常在单一维度过关、另一维度翻车（如订阅能生成但 Worker 侧拨号不通——技术视角缺） |
| **修复策略（最小切片 + repair-log）** | 修坏了常整盘重做；没有 repair-log | 同类问题反复修、修完不留档，下次换人又从头摸索 |
| **审核层自检** | 没有“某层长期全绿要不要怀疑它失效”的动作 | verifier 第 2、3、4 条未接，长期没人追问——等于结构层缺了三条还没人发现 |

## 补哪一层最划算（按成本从低到高）

1. **L4 风格层清单（最便宜，立刻做）**：四行清单，打勾 30 秒。放在每次汇报与交付之前，
   内联自查，不新增任何脚本与人力。止住的是董事长最常骂的三件事（话多、贴过程、写实名）。
2. **L2 事实层清单（便宜，立刻做）**：四行清单，要求每个数字写出来源路径。配合 L1 的
   机器比对（登记行数 = 上报数这类），不需要新系统，只需要“写报告前先对数”的动作。
   第一个情报 Harness 已按这层设计（见 `local-intel-harness/references/review-layers.md`）。
3. **verifier 补齐第 2、3、4 条（中成本）**：把结构层缺的三条接上，这是已有计划里的 M4 残留项，
   不是新工作，只是排期。
4. **终审三视角（中成本）**：独立复核从“一个人”改成“三个视角的检查表”，同一复核者按
   编辑/视觉/技术三张表逐项打勾；不需要加人，先加表。
5. **修复策略 + repair-log（低成本，改习惯）**：修失败项只修最小切片，有修复就写 repair-log；
   这是流程纪律，不花钱。
6. **审核层季度自检（零成本，定个日子）**：每季度问一次“哪层长期全绿、是不是失效了”，
   写进晨报检查项。

## 结论

我们不缺审核的数量，缺的是**分层**：L3 内容层堆了四种东西（双顾问、M4、独立复核、抽查），
L2 事实层与 L4 风格层基本是空的，L1 结构层缺三条，终审只有一个视角。
最划算的补法不是加新人、加新系统，而是先补两张 30 秒的清单（L2 + L4），再把独立复核改成三视角表。
