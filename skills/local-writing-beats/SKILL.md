# Local writing beats

## Assemble raw material into a journey of beats

- Take a markdown file of raw material as the fixed pile and commit to a path through it.

- Establish the prerequisites before any beats, settling what the audience already knows walking in.

- Ground every concept before a beat leans on it, by prerequisite or by an earlier beat.

- Write 2 to 3 candidate starting beats, show them to the user, and let the user pick one.

- Write only the picked beat to the article file, then stop there.

- Re-read the article file from disk, then offer 2 to 3 candidate next beats that are reachable from the current grounded set.

- Loop until the article reaches a natural end, and leave leftover fragments unused when the journey is complete.
